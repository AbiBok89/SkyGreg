# SkyGreg

Индустриально-технологическая скайблок-сборка для **AbiLauncher** на базе **GregTech CEu Modern**, **Applied Energistics 2** и **SkyblockBuilder**.

- **Версия сборки**: `2.7.1`
- **Minecraft**: `1.20.1`
- **Загрузчик**: `Forge 47.4.13`
- **Java**: `17`
- **Рекомендуемая память**: `8192 МБ`

Метаданные лаунчера находятся в папке [`ForLauncher/`](ForLauncher/).
